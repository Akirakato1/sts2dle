# Concise README Design

## Goal

Replace the repository's long operational README with a compact public introduction to STS-dle.

## Content

The README will contain only:

- the project name and one-sentence description;
- a prominent link to the live site;
- one short line for each mode: Daily, Hardcore Daily, Practice, and Search;
- one sentence stating that player progress is stored locally in the browser;
- concise Spire Codex, Mega Crit, and third-party-notice attribution.

## Removed Material

Remove installation, development, testing, snapshot-release, Render deployment, runtime architecture, storage-schema, and detailed comparison-rule documentation. Do not include the seven-feature list.

## Verification

Confirm the README contains no setup commands or deployment instructions, all four current modes are named accurately, the live link works syntactically, and required attribution links remain.
